# EFEX — Design Challenge

Rediseño del dashboard de EFEX: diagnóstico, diseño final (3 personas: Juan, María, AgroLog) y decisiones explicadas.

**Entrega completa:** [index.html](./index.html) (o vía GitHub Pages, una vez publicado)
**Mockup interactivo:** [mockup.html](./mockup.html)

## Contenido

- `index.html` — la entrega escrita: diagnóstico, rediseño, decisiones, hallazgos cruzados.
- `mockup.html` — mockup interactivo del dashboard rediseñado (3 casos: Juan, María, AgroLog).
- `01-diagnostico.md` — diagnóstico priorizado (3 problemas).
- `02-diseno-final.md` — wireframes de texto de las 3 variantes.
- `03-decisiones-explicadas.md` — decisiones de diseño, qué se dejó fuera, uso de IA.
- `04-extensiones-opcionales.md` — boceto del flujo de Rate Lock y de "dinero en tránsito".
- `auditoria-ui-heuristicas.md` — auditoría de heurísticas de Nielsen sobre el dashboard actual.

Hecho con asistencia de IA (Claude), divulgado en la sección "Sobre usar IA" de la entrega.
